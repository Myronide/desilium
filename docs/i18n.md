# Translations (settings app)

The settings app (`crates/desilium-settings`) has a small translation layer in `src/i18n/`.

- **English is the source language and lives in the code.** Every call site passes its English text
  as the fallback: `tr("ui.toast.undo", "Undo")`. A missing key therefore shows English, never a
  blank or a key.
- **German lives in `assets/i18n/de.toml`**: one `"dotted.key" = "text"` line per message. The file
  is embedded in the binary. Quote the keys so the dots stay part of the key.
- **The language follows the environment**, in gettext order: `LANGUAGE` (a colon separated list),
  `LC_ALL`, `LC_MESSAGES`, `LANG`. The first non-empty entry decides: `de`, `de_DE.UTF-8`, `de@euro`
  select German; everything else (also `C`) selects English. There is no setting for it yet.
- `cargo run -p desilium-settings --example render -- --lang de --page keyboard` renders a page in a
  chosen language.

## Key naming scheme

Keys are lowercase; segments use `a-z`, `0-9`, `_` and `-` and are separated by dots. Multi-word
names use `_`; option values keep the spelling of the stored value (`auto-hide`).

| Key | Text |
|---|---|
| `page.<slug>` | sidebar label and heading of a page (`page.panel`); planned pages too (`page.privacy`) |
| `page.<slug>.subtitle` | sentence under the heading |
| `section.<page>.<slug>` | card title; the slug is the English title in snake case (`section.appearance.accent_color`) |
| `setting.<setting id>.title` / `.description` | row title and explanation; the id is the registry id (`setting.appearance.theme.title`) |
| `setting.<setting id>.keywords` | extra search words, comma separated; searched next to the English ones |
| `setting.<setting id>.placeholder` | hint of an empty text field |
| `choice.<setting id>.<value>` | label of one option of a segmented control or dropdown; accent swatches use `choice.appearance.accent.<name>` |
| `action.<action name>` | shortcut action label, named as in the config file (`action.snap-left`) |
| `ui.<area>.<name>` | everything else: buttons, hints, notices, errors, key names (`ui.keyboard.swap`) |

Variable parts are `{name}` placeholders filled by `tr_args`; German may reorder them.

## Adding a string

1. Pick the key from the table; call `tr(key, "English")` (or `tr_args`). Registry entries need no
   code: `SettingDef::title_text()` and friends build the keys from the setting id.
2. Add the German line to `de.toml`.
3. `cargo test -p desilium-settings` checks that every key used by the code (registry, pages,
   sidebar, actions, swatches and every `"ui.…"` literal in the sources) exists in `de.toml`, that
   `de.toml` has no unknown keys, that every key follows the scheme and that placeholders are known.

Not translated: texts that come from other crates (repair messages of `desilium-config`), stderr
diagnostics, setting ids, file names and the names of wallpapers and cursor themes.
